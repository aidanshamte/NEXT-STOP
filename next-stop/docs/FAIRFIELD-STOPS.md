# Fairfield University boarding points: research and suggestions

Researched 2026-11-08 for the 23 stops on the Fairfield "Shuttle Bus Stops" sign (`server/imports/fairfield-university-shuttles.json`). The suggestions are in `server/imports/fairfield-university-stop-suggestions.json` and appear to administrators under **Setup → Suggested boarding points**.

## What was found

No source publishes where Fairfield shuttles actually stop, so **no stop was confirmed automatically**. Every point below is a suggestion that an administrator approves with one tap (ideally after checking it on site or in satellite view). Until then the stop stays a draft: riders cannot see it or request pickup there.

## Rules the app enforces

- A suggestion never makes a stop boardable; only an administrator’s approval or pin does (`tests/suggestions.test.mjs`).
- Approval uses the coordinates in the shipped file, not anything the client sends, and records "Approved suggestion (confidence): basis", the administrator and the time.
- Confirmed stops (including any stop an administrator already pinned) are never changed by a suggestion; approving one returns 409.
- Suggestions are matched by institution name and the stop’s import key, so no other institution sees them.
- To replace a suggestion, edit the JSON file and deploy; to reject one, skip it and pin the stop on site.
