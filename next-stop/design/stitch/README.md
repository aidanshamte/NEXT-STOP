# NEXT STOP — Stitch design references

Seven original displayed HTML screen sources extracted from the user-shared Stitch project:
https://stitch.withgoogle.com/projects/5762300554121294664

This is a design reference package, not application source or an official full-project export. The two prototype-flow placeholders and the standalone generated photograph are not included. Fonts, images, and CDN styling may require internet. HTML files retain the original source, including example scripts; review before executing.

## Screens

Start with `06-rider-live-map-and-pickup.html`, then `01-stop-details.html`. The other references cover profile/settings, location sharing, schedules, registration, and emergency UI. `index.html` links to all seven. No dedicated driver, parent, or administrator screen was visible in this shared project; do not claim those were exported.
